## Development Workflow

### AI-Assisted Development

QuDAG uses Claude and other AI tools to accelerate development while maintaining code quality:

- **Perfect Information Framework**: Gather complete context before implementation
- **Structured Commits**: Logical, reviewable commit history
- **Best Practice Enforcement**: AI ensures adherence to project standards
- **Documentation Generation**: Automatic generation of comprehensive documentation

### Code Quality Standards

- **Conventional Commits**: All commits follow conventional format
- **Test Coverage**: Comprehensive testing across all platforms
- **Security Review**: Quantum-resistant cryptography validation
- **Performance Benchmarks**: Regular performance monitoring

## Contributing

1. **Setup Development Environment**

   - Install Rust toolchain with ARM64 support
   - Configure OpenSSL for your platform
   - Set up testing environment

2. **Follow Project Patterns**

   - Use structured commit messages
   - Add comprehensive documentation
   - Include tests for new features
   - Validate across platforms

3. **Use AI Assistance Effectively**
   - Provide complete context to AI tools
   - Verify AI-generated code thoroughly
   - Document AI-assisted decisions
   - Maintain human oversight
